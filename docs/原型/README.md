# 賽事紀錄工具：互動範例原始碼

2026-09-29～09-30 在 claude.ai 討論時做的互動原型，**只當參考，不是正式程式碼**。
規格以上一層的 `賽事紀錄工具_構想.md` 與 `賽事紀錄工具_規則漏洞清單.md` 為準。

## 為什麼不能直接用瀏覽器打開

這些是 claude.ai Design 畫布的 `.dc.html` 格式，需要畫布提供的執行環境（`support.js`）才會運作，
直接雙擊打開只會看到未渲染的模板。要實際操作，請到 claude.ai 開啟原本的畫布：

- 「賽事紀錄工具範例」：打席輸入、討論整理、賽中調度
- 「打席與調度串接範例」：14 步導覽

## 檔案

| 檔案 | 內容 | 可參考的部分 |
|---|---|---|
| `打席輸入.dc.html` | 打席輸入（上壘／出局 → 類型 → 守位 → 跑者確認） | `buildPlan`（跑者預設推進）、`confirm`（出局數、得分、犧飛／雙殺標記、跑壘事件造成第三出局時打者續打）、復原 |
| `賽中調度.dc.html` | 先換人，再排守位；一般／DH 兩種賽制 | `doSub`（代打接任 DH 不取消）、`tapPos`（守位互換、DH 改守觸發取消的連動）、`check`（守位重複／缺位檢查） |
| `打席與調度串接導覽.dc.html` | 固定導覽，示範四個調度入口、時間軸、承繼跑者、復原 | 畫面切換與時間軸的呈現方式 |

## 閱讀方式

- `<script type="text/x-dc">` 裡的 `class Component` 是邏輯，`renderVals()` 算出畫面要用的資料。
- 上方 `<x-dc>` 裡是畫面模板：`{{名稱}}` 對應 `renderVals()` 的回傳值，`<sc-for>` 是迴圈，`<sc-if>` 是條件。
