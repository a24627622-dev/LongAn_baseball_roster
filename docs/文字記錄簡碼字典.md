# 龍安棒球隊 比賽文字紀錄規則 v2

> **2026-09-28 定案**（取代 2026-09-14 的 v1 草案「中文簡碼＋姓名」寫法）。
> v1 改版原因：實際比賽紀錄（2026-08-30 G4 對雨人）用的是**計分員標準符號**（`4-3`、`F9`、`K`、`BB`），
> 比中文簡碼更精準，記錄員也已經習慣。v2 以實際寫法為準，中文簡碼當同義詞保留。
>
> 記錄員在手機上看的速查表：`/tools/record-guide.html`（工具大廳也有入口）。

## 用途與流程

```
記錄員場邊的口語紀錄 ──▶ 轉換工具（/tools/）──▶ 文字轉播頁（公開，CPBL 式）
                                           └─▶ 打者／投手成績（寫進試算表）
```

- **規則式解析，不用 AI**：靠符號和固定格式辨識，精準、免費、結果可以重現
- 描述文字（「三壘邊線安打」「游擊上方飛球」）**自由寫**，程式不解析，原樣顯示在文字轉播上
- 程式看不懂、或推算結果和記錄員寫的狀態對不上時，一律標 **⚠️** 交給人確認，**絕不默默略過**

## 1. 整體格式

每個半局一個標題，底下每位打者一行（空行可有可無）：

```
一局上｜龍安攻
#56：4-3 滾地刺殺 ➔ 1 Out
#17：BB 保送上壘 ➔ 1 Out, 1B
...

一局下｜雨人攻
1棒：K
2棒：1B
...
```

### 1.1 半局標題

`X局上｜龍安攻` 或 `X局下｜雨人攻`。

- 局數用國字（一、二…）或數字都可以
- 後面括號可以寫得分，例如 `（得分：2）`，**程式會拿它和逐行加總核對**，不一致就標 ⚠️
- 寫「（比賽結束）」「（紀錄未完整）」這類備註也可以，程式忽略

### 1.2 打者行

```
打者：結果 描述 [N分進帳，龍安 X:Y] ➔ 出局數, 壘包
```

| 部分 | 必填 | 說明 |
|---|---|---|
| **打者** | ✅ | 龍安寫 `#背號`（例 `#56`）或 `N棒`（例 `7棒`）；對手一律寫 `N棒` |
| **結果** | ✅ | 第 2 節的符號，一行一定要有一個打席結果 |
| 描述 | | 自由寫，原樣顯示 |
| `[N分進帳…]` | 有得分時 | 這一行總共得幾分；比分可寫可不寫，有寫就拿來核對 |
| `➔ 出局數, 壘包` | 建議寫 | 這一行**結束後**的狀態，程式拿它和自己推算的核對 |

**壘包寫法**：`1B`、`2B`、`3B`、`1B/2B`、`2B/3B`、`1B/3B`、`滿壘`；沒人在壘上就只寫出局數。
> `1B`、`2B` 同時是「一壘安打／二壘安打」和「一壘／二壘」。**`➔` 後面的一律當壘包**，前面的當打擊結果，不會混淆。

**一行有好幾個動作時**用 `➔` 串起來，**最後一個 `➔` 後面才是狀態**：

```
#56：WP 跑者推進二三壘 ➔ 6 游擊平飛未接形成 2B 安打 [2分進帳，龍安 4:0] ➔ 0 Out, 2B
```

### 1.3 對手半局（簡記）

對手的打者**只要寫結果**，描述和狀態都可以省略：

```
三局下｜雨人攻
9棒：K
1棒：3U
2棒：1B
3棒：E6
4棒：1B
5棒：K+PB [1分進帳]
```

- 有記的局，會自動算出我方投手的投球局數、被安打、四壞、三振、失分
- 某一局來不及記，就寫一行 `未記錄`，那一局的投手成績改由人工補

## 2. 結果符號

**顯示**欄是文字轉播上看到的樣子（比照 CPBL）。**打數**：算不算一個打數（AB）。

### 2.1 安打（算打數、算安打）

| 寫法 | 同義詞 | 顯示 | 說明 |
|---|---|---|---|
| `1B` | 一安、內安 | 一安 | 一壘安打（內野安打也寫 `1B`，描述寫「內野安打」） |
| `2B` | 二安 | 二安 | 二壘安打 |
| `3B` | 三安 | 三安 | 三壘安打 |
| `HR` | 全打 | 全打 | 全壘打（打者自動算得分） |

### 2.2 四壞、觸身（算打席、不算打數）

| 寫法 | 同義詞 | 顯示 | 成績 |
|---|---|---|---|
| `BB` | 四壞 | 四壞 | 打者 BB＋1、投手 BB＋1 |
| `IBB` | 故意四壞 | 故意四壞 | **算 BB**（打者、投手都是 BB＋1）；次數另外保留在比賽資料檔 |
| `HBP` | 觸身、死球 | 死球 | **不是保送**：打者 HBP＋1、投手 HBP＋1 |

> 打席（PA）＝上場打擊的次數；打數（AB）＝打擊率的分母。四壞、故意四壞、觸身、犧飛、犧觸都**算打席、不算打數**。

### 2.3 三振（算打數）

| 寫法 | 同義詞 | 顯示 | 說明 |
|---|---|---|---|
| `K` | 三振 | 三振 | 揮空三振 |
| `ꓘ`（反寫的 K） | 見振 | 三振 | 站著被三振 |
| `K+PB`、`K+WP` | | 三振 | 不死三振，打者因捕逸／暴投上壘（投手記三振，打者算打數、不算安打） |

### 2.4 出局（算打數）

守位號碼：1 投、2 捕、3 一壘、4 二壘、5 三壘、6 游擊、7 左外野、8 中外野、9 右外野。

| 寫法 | 例子 | 顯示 | 說明 |
|---|---|---|---|
| `數字-數字` | `4-3`、`6-3`、`1-3` | 二滾、游滾、投滾 | 滾地刺殺，**第一個數字**決定顯示哪個守位 |
| `數字U` | `3U` | 一滾 | 野手自己踩壘（unassisted） |
| `F數字` | `F9`、`F4` | 右飛、二飛 | 飛球接殺 |
| `L數字` | `L6` | 游飛 | 平飛球接殺（顯示同飛球） |
| `P數字` | `P6` | 游飛 | 內野高飛接殺 |
| `FF數字` | `FF2` | 界飛 | 界外飛球接殺 |
| `DP` | `6-4-3 DP` | 雙殺 | 雙殺打（出局＋2） |

中文同義詞：`二滾`、`右飛`、`界飛`、`雙殺` 等直接寫也可以。

### 2.5 其他上壘

| 寫法 | 例子 | 顯示 | 打數 | 說明 |
|---|---|---|---|---|
| `E數字` | `E5`、`E4` | 三失、二失 | 算 | 因失誤上壘（不算安打） |
| `FC` | `FC6` | 野選 | 算 | 野手選擇 |
| `4-6` ＋描述「封殺」 | `4-6 封殺` | 二滾 | 算 | 跑者被封殺、打者上壘 |
| `SF數字` | `SF7` | 犧飛 | **不算** | 高飛犧牲打 |
| `SAC` | `SAC` | 犧觸 | **不算** | 犧牲觸擊 |

### 2.6 事件（不是打席結果，寫在打者行裡或括號裡）

| 寫法 | 說明 |
|---|---|
| `SB` | 盜壘成功，例：`（#39 SB 盜上二壘）` |
| `CS` | 盜壘失敗（只顯示在文字轉播，不進試算表） |
| `WP` | 暴投 |
| `PB` | 捕逸 |
| `BK` | 投手犯規 |

## 3. 換人（一定要寫在發生的位置）

轉換工具靠「陣容調度工具上傳的打序和換人紀錄」知道誰是誰，但**不知道是第幾局換的**，
所以記錄員要在發生的那一行標出來。文字轉播上會插一行「更換代打：A=>B」。

| 情況 | 寫法 |
|---|---|
| 代打 | `#49（代打）：P6 游擊上方高飛接殺 ➔ 2 Outs` |
| 代跑 | 在那一行加 `（二壘跑者 #17 更換代跑 #5）` |
| 守備替補 | 半局開頭獨立一行：`#55 替補 #2 守左外野` |
| 我方換投 | 獨立一行：`更換投手 #56` |
| 對手換投 | 獨立一行：`雨人更換投手`（後面可以加描述，例：`（低肩側投）`） |

> 盡量寫**背號**。暱稱（例：`Haowei`）也認得，前提是球員名單裡有登記這個暱稱。

## 4. 得分、打點（程式推算，可以手動指定）

- **誰得分**：程式追蹤每位跑者的位置，推算 `[N分進帳]` 是誰回來的。推不出來時標 ⚠️ 讓人選
- 想明確寫也可以：`（#17、#93 回本壘）`
- **打點**預設規則：

| 情況 | 算打點 |
|---|---|
| 安打、全壘打、犧飛、犧觸 | ✅ |
| 滿壘四壞、滿壘觸身 | ✅ |
| 滾地球出局時擠回分數 | ✅ |
| 失誤造成的得分 | ❌ |
| 雙殺打 | ❌ |
| 暴投、捕逸、投手犯規、盜壘 | ❌ |

- 要推翻預設時，在行尾寫 `打點N`（例：`打點0`、`打點2`）

## 5. 成績怎麼算（2026-09-27 定案）

| 項目 | 規則 |
|---|---|
| 打者成績 | AB、R、H、2B、3B、HR、RBI、BB、K、SB 全部從紀錄算 |
| 觸身球 | **獨立記 HBP，不算保送**（2026-09-28 使用者更正，依 MLB 規則）。打者表目前沒有 HBP 欄，**第 6 項（成績上傳 GAS）時新增**，OBP 同時改成（H＋BB＋HBP）÷（AB＋BB＋HBP）；在那之前只記在文字轉播和比賽資料檔 |
| 故意四壞 | 算 BB；另外保留次數在比賽資料檔，試算表不另開欄位 |
| 盜壘失敗 | 只顯示在文字轉播，不進試算表 |
| 犧飛 | 不算打數（打者表沒有犧飛欄，OBP 分母和 MLB 算法有些微差異，接受） |
| 團隊失誤數（比分表的 E） | 這版不做，維持手動 |
| 投手成績 | 投球局數、被安打、四壞、三振、失分從對手半局算；**責失分、勝投、救援人工填** |
| 寫入試算表 | 整場重算覆蓋，覆蓋前列出會改動的格子讓人確認；沿用「-」列慣例和既有的成績保留機制 |

## 附錄：v1 草案（2026-09-14）的差異

v1 用中文簡碼＋姓名（例：`→ 林廷軒:二安,打點2／梁佑丞:得分`），並規定「不追蹤壘包」。v2 的改變：

- 符號改用計分員標準寫法，中文簡碼當同義詞
- 打者用背號或棒次，不用姓名
- 壘包改為程式推算＋和記錄員寫的狀態核對
- 新增對手半局簡記、換人時間點的寫法
- v1「尚待確認事項」四題已於 2026-09-27 定案（第 5 節）
