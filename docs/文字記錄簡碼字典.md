# 龍安棒球隊 文字記錄簡碼字典 v1(草案,持續補充中)

用途:記錄員在場邊用文字記錄整場比賽經過,之後由 `stats.html`(改建後)或 GAS 端的規則式解析器,依此字典把文字轉換成結構化成績(AB/H/R/RBI/BB/K⋯),自動同步進 Google 試算表。**不使用 AI 模型解析,純規則式(字串比對/正規表示式)處理**,原因是格式已結構化、不需要語意理解,規則式更精準、免費、無需外部 API。

---

## 記錄格式總規則

每一行 = **自然語言描述**(給人看,想怎麼寫都可以,方便複盤回顧,程式不解析這段)+ **結構化事件清單**(給程式解析,格式固定)+(可選)即時比分。

```
[棒次/情境]　自然語言描述這一球發生了什麼事,愛怎麼寫都可以。
　→ 姓名1:簡碼1[,打點N]／姓名2:簡碼2／姓名3:簡碼3⋯　(比分 X:Y)
```

規則:
- 事件清單裡,一個「姓名:簡碼」為一組,多組用「／」分隔。**一行可以同時記錄打者本人 + 任意數量的跑者事件**(得分、被封殺⋯),不限於打者才能有簡碼。
- 打點是可選附加寫法,格式「簡碼,打點N」,只接在**打者自己那組**後面。沒寫就是 0 分打點,是否認列由記錄員主觀判斷(尤其發生守備失誤時,這分是否算打點屬於正式棒球規則裡的主觀判定,原則與「責失分」相同)。
- 姓名一律使用球員名單上登記的姓名(或暱稱),系統會比對球員名單;比對不到的名字會被列入「⚠️ 無法辨識」清單,交由人工確認,不會被默默忽略掉。
- **不追蹤壘包狀態**:系統不會自己去推算「誰現在在幾壘」,每一行都必須是自己說清楚「誰、發生了什麼事」的完整資訊,不能只寫「2壘跑者」這種不具名的寫法。

## ① 打者安打類(算 AB,算 H)

| 簡碼 | 說明 |
|---|---|
| 一安 | 一壘安打 |
| 二安 | 二壘安打(2B+1) |
| 三安 | 三壘安打(3B+1) |
| 全打 | 全壘打(HR+1;打者同時算得分,不需要額外寫「得分」) |

## ② 保送與觸身(不算 AB)

| 簡碼 | 說明 |
|---|---|
| 四壞 | 四壞球保送(BB+1) |
| 觸身 | 觸身球(HBP+1;若嫌麻煩可直接寫「四壞」代替,不強制分開) |

## ③ 出局類——依守位(算 AB,不算 H)

| 簡碼 | 說明 |
|---|---|
| 投滾／捕滾／一滾／二滾／三滾／游滾 | 該守位處理的滾地球出局 |
| 投飛／捕飛／一飛／二飛／三飛／游飛／左飛／中飛／右飛 | 該守位處理的高飛球或平飛球出局 |

## ④ 三振(算 AB,不算 H)

| 簡碼 | 說明 |
|---|---|
| 三振(揮) | 揮棒落空三振 |
| 三振(看) | 看第三顆好球三振 |

兩者對成績的影響相同(K+1、AB+1),差別只在文字紀錄的細節,方便回顧。

## ⑤ 特殊上壘或出局(算 AB,不算 H,除犧飛/犧觸外)

| 簡碼 | 說明 |
|---|---|
| 犧飛 | 高飛犧牲打(AB 不算) |
| 犧觸 | 犧牲觸擊(AB 不算) |
| 野選 | 野手選擇上壘(防守方選擇處理別的跑者,無守備失誤;AB 算,H 不算) |
| 失誤上壘 | 因守備失誤而上壘(AB 算,H 不算;若造成失分,是否算打點由記錄員自行判斷) |

## ⑥ 跑者專屬事件(標注在該跑者自己的名字後面,不是打者)

| 簡碼 | 說明 |
|---|---|
| 得分 | 跑回本壘(R+1) |
| 封殺出局 | 跑壘中被封殺(記一次出局事件) |
| 觸殺出局 | 跑壘中被觸殺(記一次出局事件) |
| 盜壘成功 | SB+1 |
| 盜壘失敗 | CS+1(可選欄位,不記也不影響其他計算) |

## ⑦ 投手端固定句型(半局結束或換投時,獨立一行,不是「姓名:簡碼」格式)

| 寫法 | 說明 |
|---|---|
| 本局失分:N | 累加到當局投手的 R |
| 責失分:N | 累加到當局投手的 ER(不確定就先跟失分寫一樣,預設「失分=責失分」,事後可人工調整 ERA) |
| 換投:XXX 接手 | 標記投手交接點,之後的失分算新投手的 |
| 暴投／捕逸 | 純紀錄用,目前不影響任何計算欄位 |

## ⑧ 代打／代跑(草案,尚未用實際 case 驗證,下一輪確認)

| 寫法 | 說明 |
|---|---|
| 代打:XXX 代替 YYY | YYY 被換下場,XXX 代打上場 |
| 代跑:XXX 代替 YYY | YYY 被換下場,XXX 代跑上場 |

## 已用 case 驗證過的範例

**一般安打得分**
```
1. 蘇垣華　三壘方向滾地球，內野安打。
　→ 蘇垣華:一安　(1:0)
```

**一次貢獻多分打點(2、3壘有人,打者二安,兩名跑者回本壘)**
```
5. 林廷軒　擊出中右外野方向二壘安打，三壘跑者梁佑丞、二壘跑者黃宥憬相繼回本壘得分。
　→ 林廷軒:二安,打點2／梁佑丞:得分／黃宥憬:得分　(3:0)
```

**封殺+守備失誤+得分同時發生(1出局,1、3壘有人)**
```
3. 陳奕瑋　擊出游擊方向滾地球。游擊手傳二壘，一壘跑者林廷軒遭封殺出局；二壘手轉傳一壘時發生守備失誤，陳奕瑋因此安全上壘；三壘跑者李浩瑋趁亂回本壘得分。
　→ 陳奕瑋:失誤上壘／林廷軒:封殺出局／李浩瑋:得分　(2:1)
```
(此球未記打點,因失分主要由守備失誤造成,判定不算打點)
