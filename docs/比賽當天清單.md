# 比賽當天清單

> 2026-10-24 建立（使用者定案 B1～B5：放 `docs/`、分賽前／比賽中／賽後三段、標註角色、附出狀況處理與演練附錄）。
> 依據：2026-10-24 兩次演練（從點名到發布、一鍵發布的發布／更新／撤回）。流程或按鈕有改時，這份要跟著改（V01.16.00 已更新：龍安調度與紀錄工具）。

**角色**（同一個人兼任也照這份走）
- 📱 **記錄員**：手機，陣容調度＋實況賽事紀錄
- 💻 **發布者**：電腦，賽後在「賽事成績發布」按一鍵發布

工具都在官網最下面的「**球隊管理**」：https://longan-baseball.pages.dev/tools/

---

## 一、賽前（前一天）

- [ ] 💻 **時程**：這場比賽在時程上，日期、對手、時間、地點都對；賽事（例「大漢聯盟」）有填。
      → 賽後一鍵發布要靠「同一天、同對手」找到這場，**對手名稱要和比賽當天在陣容調度填的一模一樣**
- [ ] 📱 **登入**：用要記錄的手機打開「球隊管理」，不用輸入密碼就進得去。要輸入的話先登入（一次有效 30 天）
- [ ] 📱 **手機**：充飽電；帶行動電源。球場沒訊號也能記，有訊號時會自動補傳
- [ ] 📱 （換新手機時）先在這支手機打開一次陣容調度和實況賽事紀錄，確認畫面正常

## 二、比賽中

- [ ] 📱 **龍安調度與紀錄工具**（球隊管理第一張卡）：① 點名 → 最上面按「📅 今天：… vs 對手」帶入日期和對手（和時程一樣）→ 勾出席的人 → 底部「下一步：排先發」→ ② 排先發 → 底部「📤 上傳先發」
- [ ] 📱 底部「**複製 LINE 打單**」貼到球隊群組
- [ ] 📱 按底部「**⚾ 開始比賽 ➔**」進入 ③ 比賽紀錄（自動帶入比賽與先發）
- [ ] 📱 **實況賽事紀錄**：逐打席記錄；換人、換投手按上方「調度」。每個半局結束會自動雲端備份（畫面上方「☁ 雲端已備份 N 筆」）
- [ ] 📱 比賽結束：最下面「**比賽完成**」→ 確定。成績、最終名單、逐局比分、ER 建議值會寫進試算表的比賽分頁
- [ ] 📱 比賽完成畫面：「**複製 LINE 打單**」貼到群組（最終名單）
- [ ] 📱 確認畫面寫「☁ 整場紀錄已備份到雲端」，再按「**結束，清除這台裝置的紀錄**」

## 三、賽後（電腦，比賽當天或隔天）

- [ ] 💻 打開「**🏆 賽事成績發布（電腦）**」→ 來源選「實況賽事紀錄（雲端備份）」→ 選這場
- [ ] 💻 **2. 檢查**：有 ⚠️ 就看一下，不懂的先問
- [ ] 💻 **4. 自責分（ER）確認**：每位投手的 ER，**黃色的要特別確認**（工具沒把握），不對就直接改
- [ ] 💻 **5. 一鍵發布**：
  - 綠框寫「時程：… → 比分 …、連到這場的賽事成績」
  - 賽事：確認是對的（友誼賽選「友誼賽（不計戰績）」）
  - 公告：預設勾「同時發一則戰報公告」，標題、內文可以改
  - 按「**🚀 一鍵發布**」→ 確定 → 出現「✅ 發布賽事成績：…」
- [ ] 💻 1～2 分鐘後確認官網：賽事成績頁、時程的比分、戰績、公告（綠框裡有連結）
- [ ] 💻 LINE 群組打 `#上一場`、`#戰績` 看數字對不對（`#上一場` 只算今天以前的比賽，當天就看得到）

## 四、出狀況時

| 狀況 | 怎麼辦 |
|---|---|
| 記到一半要**換手機** | 新手機：球隊管理最下面展開「🧰 備援工具」→ 實況賽事紀錄 → 填一樣的日期、場次、對手 →「讀取先發名單」→ 展開「備用（換手機、紀錄不見時）」→「**從雲端備份載入**」。只接得到最後一次雲端備份；**舊手機不要再記** |
| 球場**沒網路** | 照常記，紀錄存在手機。有訊號時按「立即備份」或等它自動補傳。保險起見可以按「下載備份檔」 |
| 「比賽完成」**寫入失敗** | 比賽完成畫面按「**重新寫入比賽分頁**」。陣容調度沒上傳過先發的話寫不進去，先回陣容調度上傳 |
| 一鍵發布出現「**時程裡沒有這場**」 | 時程編輯器新增或修正這場（日期、對手要和紀錄一樣），存到 GitHub，等 1～2 分鐘再按 |
| 一鍵發布出現「**GitHub 金鑰無效或過期**」 | 照 `DEVELOPMENT.md`「賽事成績一鍵發布」重新產生金鑰、換掉 GAS 的 `GITHUB_TOKEN`。急的話先用頁面最下面「🧰 備用：手動發布」 |
| 按鈕下方寫「**無法向 GitHub 確認…**」 | 還是可以發布；只是按鈕的「一鍵發布／更新發布」可能不準。通常是沒網路或還沒登入 |
| **發錯了**（比分、ER、選錯比賽） | 修正後按「**🔄 更新發布**」覆蓋；整場不該發的話按「**撤回這場的發布**」（刪成績、清時程比分與連結、刪戰報公告） |
| ER 改錯想重來 | 直接在發布頁改 ER 再按「更新發布」，試算表也會跟著改 |

## 附錄：演練怎麼做

正式比賽前想再整套試一次時（2026-10-24 就是這樣做的）：

1. **時程編輯器**：挑一天（例如某個練球日）暫時改成比賽，對手寫「**演練**」，存到 GitHub
2. 📱 **龍安調度與紀錄工具**：日期＝那天、場次 G1、對手「演練」→ 點名 → 先發 → 上傳 → 開始比賽
3. 📱 **實況賽事紀錄**：記一局上下就好 →「比賽完成」
4. 💻 **賽事成績發布**：選這場 → ER → 一鍵發布 → 看官網、LINE → 再按一次「更新發布」（公告不會變兩則）→「撤回這場的發布」（官網恢復）
5. **清除**（全部做完才算結束）：
   - [ ] 時程編輯器：那天**改回原本的樣子**（練球、時間、地點、拿掉賽事）
   - [ ] 試算表：刪掉「`日期_G1_演練`」和「`賽事紀錄_日期_G1_演練`」兩個分頁
   - [ ] 手機：實況賽事紀錄「結束，清除這台裝置的紀錄」；陣容調度如果還停在演練，按「🗑️ 重置」（**不要**按「比賽結案」）
   - [ ] 撤回沒按到的話：GitHub 上還會有 `data/games/日期_G1_演練.json` 和一則演練公告，再到發布頁按一次「撤回」
