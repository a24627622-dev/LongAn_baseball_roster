# 管理者權限：改用 Google 帳號登入（構想）

> 📥 2026-10-05 使用者提供（原文照錄於下方「使用者提案」），Claude 的評估與排程在最後一節。
> 這個 repo 是公開的：**管理者的 email 名單、密碼都不要寫進這份文件或任何 repo 檔案**。

## 使用者提案

建議做法：**官網用 Google 帳號登入，GAS 依 email 判斷是不是管理者**。

### 分工

| 角色 | 負責 | 說明 |
| --- | --- | --- |
| 官網（GitHub Pages） | 「請你登入」 | 點進球隊管理時跳出 Google 登入，沒登入就不顯示管理功能。只是門簾，方便使用，不是真正的鎖。 |
| GAS | 「判斷你能不能做」 | 每次上傳或修改資料，都驗證登入身分、比對管理者名單，不在名單裡就拒絕。這才是真正的鎖。 |
| 管理者名單 | 誰是管理者 | 一份教練 email 清單，放在 GAS 的指令碼屬性或試算表的一張工作表，只有擁有者能改。 |

### 流程

1. 教練點「球隊管理」，用 Google 帳號登入
2. 官網取得 Google 發的 ID token（證明「我是某某 email」的通行證，有時效）
3. 上傳 lineup 時，官網把資料和 ID token 一起送給 GAS
4. GAS 向 Google 確認 token 是真的、沒過期、是發給龍安官網的
5. 取出 email 比對管理者名單，有在名單上才寫入試算表，否則回傳「無權限」

### 好處

- 不用共用密碼，也不會有密碼外流或寫在程式碼裡的問題
- 新增或移除教練只要改名單，不用通知大家換密碼
- GAS 照樣以擁有者身分執行，試算表不用分享給教練
- 官網可以繼續放在 GitHub Pages

### 需要準備的

- 在 Google Cloud 建一個 OAuth 用戶端 ID，把官網網址加進允許的來源
- 改官網：球隊管理頁加 Google 登入按鈕，上傳時附上 ID token
- 改 GAS：加驗證 token 和比對管理者名單的邏輯

### 過渡做法（改好之前）

- 進球隊管理時輸入一次密碼，存在 `sessionStorage`（關掉分頁就失效）
- 上傳 lineup 時自動帶上密碼給 GAS 驗證；GAS 回傳密碼錯誤時清掉暫存，請使用者重新輸入
- **GAS 端的密碼檢查不要拿掉**：前端密碼只是門簾，GAS 網址寫在網頁 JS 裡，任何人都能直接呼叫
- 密碼放在 GAS 的指令碼屬性（Script Properties），不要寫在前端程式碼或 GitHub repo

### 排程

GAS 的修改和「板凳名單寫進試算表」排在同一輪一起做。

## Claude 評估（2026-10-05）

### 和現況的對照

- **「過渡做法」現在已經有了，而且更完整**（V01.02.x 起，`gas/Auth.gs`，09-23 開啟 `AUTH_ENFORCED`）：
  - 共用密碼放在 GAS 指令碼屬性，不在前端、不在 repo ✅
  - GAS 每次上傳都驗證（`authGate_`），前端只是門簾 ✅
  - 差別：現在登入後存的是 GAS 發的**通行證**（HMAC 簽章、30 天），不是密碼本身；錯 10 次鎖 10 分鐘。提案的 `sessionStorage` 存密碼、關分頁就要重輸——比賽中手機切來切去很容易被要求重新輸入，**建議維持現在的做法，不改成 sessionStorage**
- **真正新增的是「改用 Google 帳號、依 email 名單判斷管理者」**：不用共用密碼、加減教練只改名單。

### 要注意的地方

1. **Google 的 ID token 只有 1 小時效期**，一場比賽兩小時，直接拿它當每次上傳的憑證，比賽中會被要求重新登入。
   建議：Google 登入只用在「登入那一下」——GAS 驗證 ID token、比對名單後，發現有的 30 天通行證（沿用 `Auth.gs`），之後上傳照舊帶通行證。比賽中不會跳登入。
2. **影響兩個工具**：陣容調度、實況賽事紀錄（共用同一個通行證）。之後若開放公告發布權限（專案現況第 11 節「其他待討論」）也能沿用。
3. **要使用者自己做的**：在 Google Cloud 建 OAuth 用戶端 ID（允許的來源加 `https://a24627622-dev.github.io`）、在 GAS 指令碼屬性填管理者 email 名單。
4. **教練要有 Google 帳號**，而且手機瀏覽器（含 LINE 內開的瀏覽器）要能跳出 Google 登入；LINE 內建瀏覽器常擋 Google 登入，要實測。
5. 共用密碼要不要保留當備援（例如 Google 登入在球場出問題時）——待決定。

- **10/25 之後、11/17 通行證到期前完成**，和提案說的「板凳名單寫進試算表」放同一輪（GAS 只部署一次）。
