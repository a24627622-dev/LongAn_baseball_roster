# 自責分（ER）建議值說明

> 2026-10-18 改寫（V01.13.00）。原「自責分手填說明」（2026-10-06，V01.12.03）。依正式記錄規則 9.16。
> 判斷寫在 `game-core.js`（`chargeRun`），測試在 `tests/test_game_core.js` 第 P 節（期望值手算）。

實況賽事紀錄按「比賽完成」時，會把每位投手的 **ER 建議值**寫進試算表比賽分頁的投手表（ER 欄），ERA 自動重算。
**工具只看記錄員按的最終結果**（失誤上壘、野選、安打、跑者推進的原因…），失誤怎麼認定由記錄員判斷。

## 1. 在試算表確認

1. 打開這場的比賽分頁（例：`2026-10-25_G1_ZERO`），往下找到投手表的 **ER** 欄
2. 每格都有註解「工具建議 X」。**黃色**的格子有判斷不準的分，註解逐條寫出是哪一分、為什麼
3. 確認後：數字不對就直接改；確認完把黃色清掉（格式 → 清除格式，或填白色）
4. 用電腦發布到官網（賽事成績發布）時，ER 讀的就是這一欄；還有黃色或空白會提醒

**重新寫入比賽分頁時**（手機再按一次「重新寫入比賽分頁」）
- 格子是空的，或還是上次工具的建議值 → 換成新的建議值
- 格子被你改過 → 保留你填的，註解寫「工具建議 X，已保留你填的 Y」，底色不動
- 舊比賽手填的 ER（沒有註解）也一律保留

## 2. 怎麼判斷（只算龍安投手）

**不算自責分**
1. 跑者靠「失誤上壘」或「捕手妨礙打擊」上壘，之後得分
2. 不死三振靠捕逸或失誤上壘（打席裡有選「捕逸」「失誤」），之後得分；靠暴投上壘的算自責。沒選原因時當作捕逸，塗黃
3. **重建半局**：出局數＋「本來會出局的失誤」（失誤上壘、捕逸／失誤的不死三振）到 3 之後，這半局的失分全部不算；在第 3 次機會那一球回來的分也不算 → 塗黃
4. 跑者靠「失誤」或「捕逸」推進，之後得分 → 照「有疑問時對投手有利」算**非自責**，塗黃。例外：被全壘打送回來的（不管有沒有那次推進都會得分）照算
5. 野選封殺了一位靠失誤上壘的跑者，打者因此上壘，之後得分 → 重建時這個打席本來是出局，不算，塗黃

**算自責分**：安打、四壞、觸身、犧牲打、其他野選、盜壘、暴投帶回的分。

**換投手**
- 承繼跑者得分：失分和自責分都算讓他上壘的投手（9.16(g)，V01.12.04 起）
- 後援投手從上場那一刻重新數出局機會，不沾換投前失誤的光（9.16(i)）：同一分可能「球隊算非自責、這位後援投手算自責」，照個人的算並塗黃。所以各投手 ER 加起來可能比球隊的自責分多，這是規則允許的

## 3. 例子（都是測試案例）

| 情況 | R | ER |
|---|---|---|
| 失誤上壘 → 下一棒兩分全壘打 | 2 | **1** |
| 兩出局後失誤上壘 → 接著兩支安打得 2 分 | 2 | **0**（塗黃） |
| 三壘有人，暴投回本壘 | 1 | **1** |
| 三壘有人，捕逸回本壘 | 1 | **0**（塗黃） |
| A 保送後被換下 → B 被敲安打，那位跑者得分 | A 1、B 0 | **A 1**、B 0 |
| 安打上壘、靠失誤推進到三壘、再靠一安得分 | 1 | **0**（塗黃） |
| 同上但被全壘打送回 | 2 | **2** |
| A 兩出局後失誤上壘換 B → B 被轟兩分全壘打 | A 1、B 1 | **A 0、B 1**（B 塗黃，9.16(i)） |
| 8/30 雨人三局下：兩出局後游擊失誤，之後 6 分 | 6 | **0**（塗黃一條） |

## 4. 記錄員要按對的地方（工具照結果判斷）

- 打者上壘是「安打」還是「失誤上壘」
- 跑者多推進的原因：「失誤」（非自責）和「趁傳球」「野選」（自責）不一樣
- 「暴投」（自責）和「捕逸」（非自責）
- 界外飛球掉球：打者之後上壘記「失誤上壘」；打者之後出局，工具不知道這次掉球（使用者決定的簡化）
- 雙殺沒成立（規則 9.12）：接球的野手掉球記「失誤」；暴傳**不記失誤**（不能假設本來會雙殺），暴傳讓跑者多跑的那部分才記「失誤」；沒傳一壘記「野選」。前位跑者已經被封殺、打者「來不及」才上一壘，規則 9.05(b)(1) 不能記安打，要記「野選」（不影響 ER，只影響打擊率）
