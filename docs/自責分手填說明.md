# 自責分（ER）手填說明

> 2026-10-06 整理（V01.12.03）。依正式記錄規則 9.16 簡化。使用者決定不放進工具畫面，只存成這份文件。

實況賽事紀錄會自動填好比賽分頁投手表的 IP、R、H、BB、SO、HR、HBP、WP，**只有 ER（自責分）要手填**。填好後 ERA 會自動重算；重新寫入比賽分頁時，手填的 ER 會保留。

## 1. 填在哪裡

1. 打開試算表裡這場的比賽分頁（例：`2026-10-25_G1_ZERO`）
2. 往下找到**投手表**（表頭：順序｜守位｜背號｜球員姓名｜更換說明｜IP｜R｜H｜**ER**｜…）
3. 每位投手的 **ER** 欄填數字（沒有就填 0）

## 2. 怎麼算

**從這位投手的 R（失分）開始，扣掉「不是投手責任」的失分**，剩下的就是自責分。

**不算自責分**
- 靠**失誤**（或捕手妨礙打擊）上壘的跑者，之後回來得分
- 跑者靠**失誤或捕逸**才多推進、才回來得分的分
- **兩出局後**，本來應該第三個出局卻因為失誤沒出局，之後這半局的失分**全部**不算

**算自責分**
- 安打、四壞、觸身、犧牲打、盜壘帶回的分
- **暴投**帶回的分（暴投是投手的責任；捕逸才是捕手的）

**換投手時壘上有人（承繼跑者）**
- 換投時已經在壘上的跑者，之後回來得分，**失分和自責分都算前任投手**（規則 9.16(g)）
- 工具的 R 已經照這個規則分好（V01.12.04 起），ER 也照同樣的人算

## 3. 例子

| 情況 | R | ER |
|---|---|---|
| 游擊手失誤讓打者上壘 → 下一棒全壘打，2 分 | 2 | **1**（失誤上壘的那位得分不算） |
| 兩出局，二壘手失誤讓打者上壘 → 接著兩支安打又得 2 分 | 2 | **0**（這局本來應該結束了） |
| 三壘有人，暴投讓跑者回本壘 | 1 | **1** |
| 三壘有人，捕逸讓跑者回本壘 | 1 | **0** |
| 投手 A 保送打者後被換下 → 投手 B 被敲安打，那位跑者回來得分 | A 1、B 0 | **A 1**、B 0 |

拿不準就先照「R 扣掉失誤、捕逸造成的分」填，賽後再跟教練確認。
