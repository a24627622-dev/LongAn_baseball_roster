文字紀錄轉換
球隊管理 速查表

1. 哪一場比賽

從試算表讀這場的打序與換人（陣容調度工具上傳的那份）。需要隊務登入，已經在陣容調度工具登入過就不用再登入。

2. 貼上文字紀錄

寫法見 記錄員速查表。貼上後會自動轉換，內容會暫存在這台裝置，不小心關掉也不會不見。

3. 檢查

載入陣容、貼上紀錄後，這裡會出現文字轉播預覽。

4. 產生資料檔並貼到 GitHub

  1. 按「產生資料檔」，再按「複製全部內容」
  2. 按「開啟 GitHub 新增檔案頁」，檔名已經填好（—）
  3. 在編輯框貼上，捲到最下面按 Commit changes
  4. 如果這場之前已經發布過，GitHub 會說檔名已存在：改按「開啟 GitHub 編輯頁」，Ctrl+A 全選後貼上
  5. 最後到 時程編輯器，在這場比賽的「文字轉播」欄填上比賽 ID（—），時程頁就會出現連結
